# Main Navigation UI Contract

## Main destinations

The persistent primary navigation presents these destinations in this order:

1. Log match
2. Requests
3. Profile
4. Global stats

Log match is selected when the app opens. The selected destination is visually distinct.

## Log match

Log match hosts the existing guided match-log flow unchanged. It starts at Choose your hero when newly opened. Leaving the destination does not save a partial match.

## Requests

Requests shows a title and a clear statement that linked-match requests are not available during the local solo test. It has no action, request list, badge, or count.

## Profile

Profile shows that the current solo-test data is stored on this device and provides a **Match history** action. That action opens the existing history screen. Its back action returns to Profile.

## Global stats

Global stats shows a title and a clear statement that community statistics are not available during the local solo test. It has no statistic values, sort controls, or network action.
