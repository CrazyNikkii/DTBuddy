# UI Contract: Match Outcome Flow

## Winner state

- Heading: `Who won?`
- Both selected heroes are visible for context.
- Two selectable choices identify the logging player and opponent.
- Back returns to opponent-hero selection.

## First-player state

- Heading: `Who went first?`
- Both selected heroes and the selected winner are visible for context.
- Two selectable choices identify the logging player and opponent.
- Back returns to winner selection.

## Temporary summary state

- Heading: `Match details chosen`
- The logging-player hero, opponent hero, winner, and first player are named clearly.
- It explains that date selection and saving will be added later.
- It offers no save action.
